One folder, seven passes

Watch the same data change shape.

Each section below is one pass over the files you dropped in. Scroll, and the same spreadsheet becomes a schema, a profile, a map, and finally a report.

01Directory Analyser

It opens the folder first.

Nine files, some nested, some in formats you forgot were in there. Everything gets opened, counted, and checked before a single number is computed.

Explore this section →

02Schema Analyser

Then it works out what each column is.

Not from the header — from the values. month is a date, revenue is a number, region is a category with four levels. Each with a confidence score you can override.

Explore this section →

03Column Profiler

Every column gets profiled.

Range, median, spread, and shape. Revenue turns out to be right-skewed, and one row sits far enough outside the rest to be worth a second look.

Explore this section →

04Relationship Mapper

Then the second file arrives.

Two columns match by value, not just by name — so these files can be joined. Two more move together strongly enough to be worth testing.

Explore this section →

05Statistics Lab

The promising pair gets tested properly.

Assumptions checked, the right test chosen, the fit drawn with its uncertainty. Revenue and ad spend move together — and about two-thirds of the variation is accounted for.

Explore this section →

06Chart Studio

Findings become charts.

A chart type is chosen for every column and every promising pair, with the reasoning attached — so swapping it is an informed decision rather than a guess.

Explore this section →

07Report Builder

And all of it lands in one document.

Every finding, chart, and caveat written out in plain language — the thing you actually send to someone who has never opened Data Lens.
