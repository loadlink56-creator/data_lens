What it finds

Two kinds of relationship, both worth knowing.

Join keys

Columns that link one file to another, found by comparing actual values — not by trusting that two columns with the same name mean the same thing.

Cardinality and match rate

One-to-one, one-to-many, or many-to-many — with the percentage of rows that actually find a partner, so you know before you join.

Correlation matrix

Every numeric column against every other, across files, with weak noise filtered out so only the pairs worth reading remain.

Orphans

Rows that reference something that isn't there — returns without an order, orders without a customer — counted and listed.

A caution worth stating

Correlation is a starting point, not a conclusion.

Data Lens will tell you revenue and ad spend move together. It won't tell you one caused the other, and it won't pretend to. Every correlation comes with its sample size, its confidence interval, and a note when the relationship is driven by a handful of points.

01

Values, not names

Key detection compares overlapping value sets. A column called id in two files only gets linked if the values genuinely correspond.

02

Fuzzy keys, flagged as fuzzy

Near-matches from whitespace, casing, or leading zeros are found and reported separately from exact matches, so you decide whether to accept them.

03

Spurious pairs get filtered

With enough columns, something will correlate by chance. Data Lens adjusts for multiple comparisons and marks the pairs that don't survive it.

04

Non-linear too

Pearson misses curved relationships. Spearman and mutual information run alongside it, so a strong non-linear link doesn't get scored as zero.
